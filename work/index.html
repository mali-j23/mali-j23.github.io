Biostatistics in R (coursework)

From my MPH biostatistics final exam (PUBH 6625): correlation, simple and logistic regression, t-tests, ANOVA, chi-square, and nonparametric tests on public teaching datasets. I'm still building my R skills; this is coursework, not production code.

# Logistic regression: diabetes by age and BMI (Pima Indians data)
df <- na.omit(PimaIndiansDiabetes2[, c("diabetes", "age", "mass")])
model <- glm(diabetes ~ age + mass, data = df, family = "binomial")
summary(model)
exp(coef(model))   # odds ratios

# Chi-square test of independence: current smoking by education (NHANES)
df <- na.omit(NHANES[, c("SmokeNow", "Education")])
tbl <- table(df$SmokeNow, df$Education)
chisq.test(tbl)

# Two-way ANOVA: BMI by race and gender (NHANES)
df <- na.omit(NHANES[, c("BMI", "Race1", "Gender")])
summary(aov(BMI ~ Race1 * Gender, data = df))
